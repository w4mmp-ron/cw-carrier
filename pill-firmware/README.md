# PlatformIO — Proficio MKII-PTT on STM32F411 (Black Pill)

The working firmware tree. (`../pio/` is Grok's original, kept for reference only.)

## Requirements

- PlatformIO Core (CLI) or VS Code + PlatformIO IDE
- ST-Link for upload/debug

## Build / flash

```bash
cd firmware/pio-claude
pio run              # normal build (goes in the radio)
pio run -t upload    # flash the app via ST-Link (0x08008000)
```

Each normal build writes to the tree-level `release/` folder:

- `app-firmware.bin`: the app @ `0x08008000` (DFU flasher or `pio run -t upload`)
- `boot-app-firmware.bin`: `bootload-PA8.bin` + 0xFF pad + app, one ST-Link flash @ `0x08000000`

The build date goes into `include/build_info.h` (auto-generated by `extra_tinyusb.py`).

**Bench build** (bare Black Pill only, never in the radio): `pio run -e bench` ignores the
codec I2C failure so the I2S/DMA LED letters show. Output: `release/app-firmware-bench.bin`,
no combined image.

## What's in it

USB (TinyUSB, `third_party_tinyusb/`): vendor control requests (same opcodes as the PSoC,
`include/usbvend.h`) + UAC2 audio (96 kHz stereo I/Q). PCM3060 codec over I2C + full-duplex
I2S DMA, SI5351 LO, CW/keyer bridge to the PIC, band/PTT/GPIO, die temp, PA NTC.
Clock: HSE 25 MHz -> 84 MHz SYSCLK / 48 MHz USB. App linked at `0x08008000`
(`ld/STM32F411CEUX_APP_0x8000.ld`) above the flash DFU bootloader.

## LED (PC13)

Morse diagnostic letters at 5 WPM: see `LED-CODES.md` (legend + results log).
